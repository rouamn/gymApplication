# Sports Hall Management System

This is a comprehensive **Sports Hall Management System** designed to streamline operations, improve user experience, and provide an all-in-one solution for managing sports hall activities. Built with **.NET**, **Angular**, and **SQL Server**, the platform features advanced authentication, secure online payment integration, an intelligent chatbot, and robust tools for managing courses, events, and more.

---

## **Tech Stack**

- **Frontend**: Angular
- **Backend**: .NET (C#)
- **Database**: SQL Server
- **Authentication**: JWT (JSON Web Token)
- **Payment Integration**: Stripe (or other secure online payment systems)
- **Version Control**: Git & GitHub

---

## **Features**

- **Authentication System**: Secure login and registration with JWT-based authentication.
- **Course Management**: Allows users to book and manage courses offered by the sports hall.
- **Event Management**: Manage and schedule events such as tournaments, fitness classes, and more.
- **Online Payment**: Secure payment system for booking courses, events, and services.
- **Intelligent Chatbot**: Personalized assistance for users to help with bookings, queries, and sports hall information.
- **User Roles**: Different roles such as Admin, User, and Manager with specific access levels and privileges.
